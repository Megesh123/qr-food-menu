# QR Food Menu Demo

Spice Street digital QR menu demo.

## Pages

- Customer: index.html
- Admin: admin.html

## Demo storage

Availability currently uses browser localStorage. This is intentional for the first GitHub Pages demo.

For production, replace localStorage with Supabase/Firebase so availability syncs between the restaurant owner's phone and customers' phones.

## GitHub Pages

Enable Pages from Settings → Pages → Deploy from branch → main → / (root).
